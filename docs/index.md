# IntelliReview AI & Shetkari Mitra - Project Documentation

Welcome to the official documentation for **IntelliReview AI**, which also encompasses the **Shetkari Mitra (Mandi Dashboard)** module. 

## Overview
IntelliReview AI is a multifaceted application built with modern web technologies that integrates Google Gemini AI to provide intelligent reviews and analysis across multiple domains, while firmly supporting the agricultural community through live market data.

### Key Modules:
1. **Automotive (CarModule)**: AI-generated car reviews, specifications, and expert recommendations.
2. **Finance (LoanModule)**: Loan eligibility analysis, interest rate comparison, and EMI calculation.
3. **News (NewsModule)**: AI-powered news summarization and sentiment analysis.
4. **Social Media (SocialModule)**: Social media monitoring using n8n automations.
5. **Agriculture (Shetkari Mitra / Mandi Dashboard)**: A dedicated portal providing live agricultural market prices in Maharashtra (via `data.gov.in`), localized weather updates, and AI-driven crop advisory in Marathi.
